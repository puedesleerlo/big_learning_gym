# 1. What would change if we acted?

If people who use a study app get higher scores, does the app help?

Original teaching notes prepared with AI assistance for this Learning Gym. These are explanatory material, not a copy of the referenced publications.

# What you will learn

Separate a description, a prediction, and a causal question.

Name an intervention, outcome, population, and time horizon.

Explain why an observed difference may have several causes.

# Intuition

Start with a decision you care about: should you spend twenty minutes using a study app tomorrow? An association describes what happened together: app users scored higher. A prediction estimates an outcome from information: knowing someone uses the app may help predict their score. A causal question compares what would happen under different actions: how would scores change if otherwise comparable learners were assigned to use the app rather than not use it?

The distinction matters because app users may already study harder. Their motivation can influence both app use and exam scores. The same observed pattern can fit a story in which the app helps, a story in which motivation explains everything, or a mixture. Causal reasoning does not mean rejecting observational data. It means making the target action and the assumptions connecting data to that action explicit.

A useful first habit is to finish this sentence: 'For this population, changing X from this alternative to that alternative would change Y over this period.' Different choices produce different causal questions. Starting an app, completing its lessons, and being offered free access are three different interventions, even if a dataset calls all of them 'app use'.

# Three questions about one dataset

A school records whether 100 learners used an app and their final scores. 'What was the average score among app users?' is descriptive. 'Can app use predict a new learner's score?' is predictive. 'What is the average effect of assigning twenty minutes of app practice each day for four weeks among first-year learners?' is causal. Only the last question specifies a change we could try to make. The recorded user/non-user difference alone does not answer it.

# Try it

In the toy model H=M and Y=50+10H+20M, compare the observed H=1 versus H=0 score difference with the effect of assigning one additional hour at fixed M. Predict both before calculating. Lesson 2 explains the model in detail.

# Remember

Association concerns observed groups; intervention concerns a change to the process generating outcomes.

Specify the action before choosing an algorithm.

A causal claim can be useful and still depend on assumptions that the data alone cannot verify.

# Common mistake

Treating a very accurate prediction as proof that changing its input will change the outcome.

# Research bridge

Discovery papers infer aspects of causal structure from data. This overview helps you see why a useful graph must address an intervention question rather than only fit correlations.

Different causal discovery approaches extract information using different assumptions; observational association by itself is not a universal route to causation.

# Assumptions

The variables and causal question must be defined meaningfully.

Each discovery method adds assumptions beyond the observed associations.

# Limits

A broad methodological overview is not evidence that a specific model or dataset satisfies those assumptions.

A discovered structure and an estimated treatment effect are different outputs.

# Reading task

Read the introductory distinction between causal discovery and causal inference. Skip the technical method details on the first pass.

Write one prediction question and one intervention question about the same dataset. Explain what additional evidence would connect the prediction to the intervention.

# Reflection

Name one decision in your work or life. Write the intervention, its alternative, the outcome, the population, and the time horizon.
